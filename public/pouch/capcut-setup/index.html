CapCutつなぐセットアップ

動画編集をClaudeに手伝ってほしいのに、CapCutとのつなぎ方がわからない

Mac の Claude Code が、CapCut とつなぐ準備を1ステップずつ案内します。つないだあとは、素材・台本・トンマナを渡すと、Claude が CapCut の下書きを作ったり直したりできるようになります。

Claude Code で使う方

スキルは、AIに作り方を教えるための説明書のようなファイルです。

  1. zipをダウンロードして、解凍します。
  2. 中の「capcut-setup」フォルダを、デスクトップなどに置きます。
  3. Claude Codeで「デスクトップのcapcut-setupフォルダを、スキルとして ~/.claude/skills に入れて」と頼み、開き直してから「CapCutとつなぐセットアップをして」と話しかけます。

Mac と Claude Code、CapCut のパソコン版（無料）が必要です。
有志が作った無料の道具「capcut-cli」を使う、非公式のつなぎ方です。CapCutのアップデートで、急に動かなくなることがあります。
動画の書き出しと投稿は、最後にご自身で CapCut から行います。
