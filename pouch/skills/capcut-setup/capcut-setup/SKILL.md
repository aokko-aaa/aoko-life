# ClaudeとCapCutをつなぐセットアップ

相手は、MacにClaude Codeを入れたばかりの人かもしれません。ターミナルや専門用語に慣れていない前提で進めてください。

## 進め方の約束（いちばん大事）

- 1回に1ステップだけ進める。終わったら「できました。次は〇〇です」と伝えてから次へ。
- 専門用語は使わないか、使うときは一言で言いかえる（例：「Node.js（道具を動かすための土台）」）。
- パソコンに何かを入れる前は、必ず「〇〇を入れます。よいですか？」と聞いて、返事を待つ。
- エラーが出たら、英語のメッセージをそのまま見せずに「何が起きたか」「次に何をするか」を日本語で短く伝える。
- 相手が「わからない」と言ったら、画面のどこを見ればいいかまで具体的に案内する。

## 最初に伝えること

始める前に、次の4つを短く伝える。

1. CapCutには公式の連携がありません。有志が作った無料の道具「capcut-cli」を使って、CapCutの「下書きファイル」をClaudeが直接書き換えるしくみです。
2. 非公式なので、CapCutのアップデートで急に動かなくなることがあります。
3. Claudeが書き換えている間は、CapCutを終了しておきます（開いたままだと、CapCutの自動保存で上書きされることがあります）。
4. 動画の書き出しと投稿は、最後に自分でCapCutから行います。

そのうえで「進めてよいですか？」と聞く。

## ステップ1：Macとアプリの確認

- `uname` でMacか確かめる。Mac以外なら、このスキルはMac向けだと伝えて止める。
- `ls /Applications | grep -i capcut` でCapCutのパソコン版が入っているか確かめる。
  - 無ければ「CapCutの公式サイトかApp Storeから、パソコン版（無料）を入れて、一度開いてから戻ってきてください」と案内して待つ。
- CapCutで、テスト用の下書きを1本作ってもらう（短い動画を1本入れて、テロップを1つ入れて保存するだけでよい）。名前は「テスト」など、あとで見つけやすいものにしてもらう。

## ステップ2：Node.js（道具を動かす土台）

- `node -v` を実行する。
  - `v18` 以上ならOK。
  - 入っていない、または古い場合：「Node.jsの公式サイト（nodejs.org）から『LTS』と書かれたほうをダウンロードして、普通のアプリと同じように入れてください」と案内する。入れ終わったら、ターミナル（Claude Code）を一度閉じて開き直してもらい、もう一度 `node -v` で確かめる。

## ステップ3：capcut-cliを入れる

次の2行を、Claude Codeの入力欄に1行ずつ入力してもらう（これはClaude Code自体への指示なので、相手に打ってもらう）。

```
/plugin marketplace add renezander030/capcut-cli
/plugin install capcut-cli@capcut-cli
```

続けて、コマンドとしても使えるように入れる（入れてよいか聞いてから）。

```
npm install -g capcut-cli@latest
```

- 古い版には安全面の問題が報告されているので、必ず `@latest`（最新版）で入れる。
- 権限のエラー（EACCES など）が出たら、`sudo` は使わずに、何が起きたかを伝えて相談する。

## ステップ4：足りないものチェック

```
capcut doctor
```

- 結果を、日本語で「そろっているもの」「足りないもの」に分けて伝える。
- FFmpeg（動画を書き出す道具）や Whisper（字幕を自動で作る道具）は、使いたい機能があるときだけでよい。今すぐ必要か相手に聞き、いらなければ飛ばしてよいと伝える。

## ステップ5：動作確認

1. CapCutを終了してもらう（「CapCut」メニュー →「CapCutを終了」）。終了したか確認してから次へ。
2. 念のため、ステップ1で作ったテスト用の下書きを使う。大事な下書きでは試さない。
3. capcut-cli の使い方は、入れたプラグインの説明と `capcut --help` を読んで確かめる（ここに書いていないコマンドを推測で使わない）。
4. テスト用の下書きの中身を読んで、「動画が1本、テロップが1つ」のように、わかったことを日本語で伝える。
5. テロップを1つ足す（文字は「Claudeから追加」など）。
6. CapCutを開いて、その下書きにテロップが増えているか見てもらう。一度保存して閉じ、もう一度開いても残っているかも確かめてもらう。

テロップが見えたら成功です。

## 最後に伝えること

- 成功したら：「これで、ClaudeにCapCutの下書きを作ったり直したりしてもらえます」と伝える。
- そのうえで、必ず次のことを伝える：このスキルは最初に1回つなぐためのもので、毎回の動画づくりには使わない。つないだだけでは思いどおりの動画にはならない。動画を作るときは、次の3つをそろえて渡すほどイメージに近づく。
  1. 素材：使いたい動画を1つのフォルダに入れて、Claude Codeでそのフォルダを選ぶ
  2. 台本：どの動画をどの順に並べて、どんな文字を入れるか
  3. トンマナ：色・文字の感じ・テンポなどの雰囲気。参考の動画があれば一緒に
  これまで作ってきたリールやショート動画があれば、その下書きを「この感じで」と見本として渡すのがいちばんの近道だと添える。
- 頼み方の例を1つ出す（例：「このフォルダの動画で、この台本どおりに下書きを作って。トンマナは下書き『〇〇』と同じ感じで」）。
- 毎回のお約束をもう一度：作業中はCapCutを終了しておく、大事な下書きは複製してから、書き出しは自分で。
- うまくいかなかったら：どこで止まったかと、表示されたメッセージを日本語でまとめて伝える。CapCutのアップデートが原因のこともあるので、`npm install -g capcut-cli@latest` で最新版にしてから試し直すよう案内する。

## してはいけないこと

- 相手のテスト用以外の下書きを、確認なしで書き換えない。
- `sudo` を使わない。
- パソコンの設定や、CapCut以外のアプリのファイルを変えない。
- CapCutの書き出し・投稿をClaudeが代わりに行おうとしない。
